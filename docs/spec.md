**APPENDIX A**  
**BATCH HEADER RECORD LAYOUT**

Sending System: Koha  
Receiving System: ERP (PL)  
Record Size: 120 characters, Fixed Length

| Internal Name     | Type      | Len | From | To  | Description                                            |
| :---------------- | :-------- | :-- | :--- | :-- | :----------------------------------------------------- |
| **Batch ID**      | Character | 4   | 1    | 4   | Unique Batch ID from source system                     |
| **Num Trans**     | Number    | 5   | 5    | 9   | Number of records in batch excluding the header record |
| **Total Debits**  | Number    | 17  | 10   | 26  | Total value of debits Format 9(14)99                   |
| **Total Credits** | Number    | 17  | 27   | 43  | Total value of credits Format 9(14)99                  |
| **Batch Date**    | Date      | 8   | 44   | 51  | Date the file was produced                             |
| **Filler**        | Character | 69  | 52   | 120 | Leave as blank                                         |

**Mandatory fields are shown in bold**

Batch ID  
A sequential number in the range 001- 999, prefixed by a source identifier K. The same ID will be used on each detail record. Upon reaching K999 batch ID to reset back to K001.

Num Trans  
Total number of detail records in the batch.

Total Debits  
Value of debit records in the batch in pence (where the amount is positive), expressed as a positive unsigned value.

Total Credits  
Value of credit records in the batch in pence (where the amount is negative), expressed as a positive unsigned value.

Batch Date  
Date the file was produced  
**APPENDIX B**  
**LINE DETAIL RECORD LAYOUT**

Sending System: Koha  
Receiving System: ERP (PL)  
Record Size: 120 characters, Fixed Length

| Internal Name     | Type      | Len | From | To  | Description                                                                           |
| :---------------- | :-------- | :-- | :--- | :-- | :------------------------------------------------------------------------------------ |
| **Batch\_ID**     | Character | 4   | 1    | 4   | Unique Batch ID from source system (same as batch header record)                      |
| **account**       | Character | 5   | 5    | 9   | Finance Account Code                                                                  |
| **costc**         | Character | 4   | 10   | 13  | Finance Costc Code                                                                    |
| **subcc**         | Character | 4   | 14   | 17  | Finance Sub-Cost Centre code                                                          |
| **analysis**      | Character | 3   | 18   | 20  | Finance Analysis code.                                                                |
| **tax\_code**     | Character | 2   | 21   | 22  | VAT Code for the line.                                                                |
| **amount**        | number    | 10  | 23   | 32  | net amount of the transaction                                                         |
| **vat\_amount**   | number    | 10  | 33   | 42  | VAT amount of the transaction if applicable                                           |
| **description**   | character | 10  | 43   | 52  | the transaction number generated by Koha (used for cross-referencing between systems) |
| **trans\_date**   | date      | 8   | 53   | 60  | date of the transaction as input in Koha                                              |
| **voucher\_date** | date      | 8   | 61   | 68  | Supplier’s invoice date as recorded in Koha                                           |
| **ext\_inv\_ref** | Character | 10  | 69   | 78  | The invoice or credit note number                                                     |
| **apar\_id**      | Character | 6   | 79   | 84  | The ERP creditor (supplier) number. Required on every transaction line                |
| **Filler**        | Character | 36  | 85   | 120 | Leave as blank                                                                        |

Batch ID  
A sequential number in the range 001- 999, prefixed by a source identifier K. The same ID will be used on each detail record. Upon reaching K999 batch ID to reset back to K001.

account  
This should be populated by account code held in Koha. Will always be R4016

costc  
This should be populated by costc held Koha. Will always be LLAA

subcc  
This should be populated by sub cost centre held in Koha. These will be coded as  
LBAB – Audio Books  
LBPB – Printed Books  
LBPP – Papers & Periodicals  
LBRO – Reference Online

analysis  
This should always be Z99

tax\_code  
Books,ebooks, papers and periodicals are classed as zero rated, please use VAT code 04 for zero rated. Audio books are classed as standard VAT 20%, please use VAT code 01 for standard rated. These are the only VAT codes that should be applicable to this interface.  
01 – Standard rated 20%  
04 – Zero rated 0%

amount  
The net (excluding VAT) amount of the invoice line in pence. For credit notes, Koha should place a minus figure before the amount

vat\_amount  
The amount of VAT for the invoice line in pence. Where the line is a credit, Koha should place a minus figure before the amount. Where there is no VAT on the line this field can be left blank.

description  
The Koha generated transaction number. This is used to cross-reference the transaction between Koha and ERP.

trans\_date  
Use the date the transaction was recorded on Koha in YYYYMMDD format (no separators)

voucher\_date  
Use the supplier’s invoice date as recorded on Koha in YYYYMMDD format (no separators).

ext\_inv\_ref  
The invoice or credit note number that was entered into Koha

apar\_id  
The creditor (ERP supplier) number as entered on the Koha supplier screen should appear on every transaction line. This is 6 digits long starting with a 5\.
